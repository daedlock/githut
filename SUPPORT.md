# Support

GitHut is community-supported open-source software.

## Questions and usage help

Use GitHub Discussions for:

- How-to questions.
- Local development setup help.
- Ideas that are not yet concrete feature requests.
- Design or workflow discussion.

## Bugs

Open a bug report when something is broken or behaving unexpectedly. Please include reproduction steps, browser/OS details, and screenshots or logs when relevant.

## Feature requests

Open a feature request when you can describe the user problem, expected behavior, and why the feature belongs in GitHut.

## Security issues

Do not use public issues or discussions for vulnerabilities. See [`SECURITY.md`](SECURITY.md).

## Response times

Maintainers review issues and pull requests as availability allows. Clear reproduction steps, focused scope, and screenshots significantly improve response time.
