
# GitHut Product:

Githut is a project aiming to replace completely the UI of github because its SSR'd and it's very slow. We want to cover the core features of github:
- Code browsing, commit browsing, branch browsing
- Issues (CRUD), reactions
- PRs (CRUD), reactions, commenting on code, browsing code
- Actions (same functionality as github, browse, execute, check logs)

This is on a high level. The authentication happens using oAuth, users gives us access to their gitub and we are able to render everything for them using the api.


# UI
- UI is simple and stays out of the way, it's perfectly whitespaced. World class quality and usability
- Suports light and dark modes
- Top notch code view and diff view
